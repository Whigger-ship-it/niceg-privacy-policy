# NiceG Privacy Policy

**Last updated: November 18, 2026**

## 1. About NiceG

NiceG is a Chrome extension that helps users hide unwanted webpage elements, manage website-specific rules, detect certain unwanted content, and apply filtering protections.

NiceG is designed to process extension data locally in the user's browser.

## 2. Information We Store

NiceG may store the following information locally using Chrome extension storage:

- **Extension settings:** User preferences and protection settings.
- **Website rules:** Rules created by the user to hide specific elements on websites.
- **Whitelist:** Websites excluded from certain filtering and protection features.
- **Statistics:** Local counts of hidden elements and recent activity.
- **Element descriptions:** When creating a rule, NiceG may store an element's HTML tag, optional element ID, and up to three CSS classes. These descriptions are used to identify and display the relevant rules in the extension interface.

Recent statistics entries are limited in number and length.

NiceG does not require users to create an account.

## 3. How Information Is Used

Locally stored information is used only to provide NiceG's features, including:

- Applying and restoring element-hiding rules.
- Remembering website-specific settings.
- Managing whitelist and filtering preferences.
- Displaying local usage statistics.
- Supporting Smart Auto detection and filtering features.

NiceG does not use this information for advertising or user profiling.

## 4. Data Sharing and Transmission

NiceG does not operate a server that collects users' browsing activity or extension data.

Stored settings, website rules, whitelist entries, statistics, and element descriptions are not uploaded to NiceG servers.

NiceG does not sell or share this locally stored information with third parties.

When users enable filter lists, the extension may download filtering rules from the corresponding external URLs. Built-in EasyList and EasyPrivacy entries use sources hosted at easylist.to. Users may also configure their own filter-list URLs.

These requests retrieve filtering rules. They do not transmit NiceG's locally stored settings or statistics to those filter-list providers.

## 5. Third-Party Services

NiceG does not integrate third-party analytics or advertising services.

External network requests may occur when users enable filter-list downloads or when the extension performs its intended website-protection functions.

EasyList and EasyPrivacy are optional built-in filter-list sources and are disabled by default. NiceG Custom is enabled by default but has no configured download URL.

## 6. Data Retention and Deletion

NiceG data is stored locally in the browser.

Users can remove stored information by using the extension's available reset or data-management features, clearing the extension's stored data, or uninstalling the extension.

Uninstalling the extension removes its locally stored extension data according to Chrome's extension storage behavior.

## 7. Permissions

NiceG uses Chrome extension permissions to provide its features:

- **Storage:** Save settings, rules, whitelist entries, and statistics locally.
- **Scripting:** Support user-directed element selection and webpage interaction.
- **Declarative Net Request:** Apply network filtering and protection rules.
- **Website access:** Allow the extension to operate on websites where the user enables its functionality.

These permissions are used to provide the extension's stated purpose.

## 8. Children's Privacy

NiceG is a general-purpose browser extension and is not specifically directed at children.

NiceG does not knowingly collect personal information from children.

This Privacy Policy may be updated when NiceG's functionality or privacy practices change.

Any updates will be published on this page with a revised update date.
